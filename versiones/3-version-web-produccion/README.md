## 📱 Acceso Rápido desde Teléfonos Móviles (Cualquier Red WiFi / Celular)

La aplicación es **100% responsiva** y se comporta como una Progressive Web App nativa en iOS (Safari) y Android (Chrome):
* **Navegación táctil fluida con 1 dedo** (desplazamiento vertical nativo sin bloqueos ni necesidad de usar 2 dedos).
* **Visor interactivo POP**: Ajuste de zoom, color de tela, subida de logos y cotizador en tiempo real.
* **Carrito y checkout directo a WhatsApp** con ficha de diseño PNG adjunta.

### 📲 Escanear Código QR:
Puedes generar un código QR hacia el catálogo copiando esta URL en cualquier generador o usando la herramienta interna de compartir:
```text
https://pop-mockup-studio.vercel.app/catalogo
```

## 🚀 Despliegue y Actualización en Producción

```bash
npx vercel --prod --yes
```
El alias de producción `pop-mockup-studio.vercel.app` se actualizará de inmediato en menos de 30 segundos.
