## 💡 Cómo Abrir con un Navegador Específico

Si deseas abrir una de las aplicaciones web en un navegador específico (por ejemplo, Google Chrome o Brave en lugar de tu navegador predeterminado):

1. Haz doble clic sobre **`Abrir-Con-Cualquier-Navegador.command`**.
2. Selecciona tu navegador:
   * `1` para **Google Chrome**
   * `2` para **Safari**
   * `3` para **Brave Browser**
   * `4` para **Firefox**
   * `5` para **Microsoft Edge**
   * `6` para el **Navegador Predeterminado**
3. Elige la web app o servicio que deseas cargar. ¡Listo!
